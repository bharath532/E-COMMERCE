# 🛒 MERN E-commerce Website

A full-stack **E-commerce web application** built using the **MERN stack** (MongoDB, Express.js, React, Node.js).  
This project is part of my learning journey and portfolio.

---

## 🚀 Features
- ✅ User authentication (Login & Register with JWT + Cookies)  
- ✅ Product listing with details & images  
- ✅ Add to Cart / Remove from Cart  
- ✅ Update product quantities in cart  
- ✅ Order management system  
- ✅ Stripe payment integration  
- ✅ Responsive design (Bootstrap + custom CSS)  

---

## 🛠️ Tech Stack
- **Frontend:** React.js, Bootstrap, Axios  
- **Backend:** Node.js, Express.js  
- **Database:** MongoDB (Mongoose)  
- **Authentication:** JWT + Cookies  
- **Payment:** Stripe
